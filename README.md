# GTAV.VisualEnhancemen

A lightweight graphics preset for Grand Theft Auto V (GTA V) that enhances image sharpness, contrast, and color vibrance using SweetFX/ReShade shaders.

## Features

- **Image sharpening:** Improves perceived image clarity.
- **Contrast enhancement:** Adjusts black and white levels.
- **Color vibrance:** Makes colors more noticeable.
- **Curves adjustment:** Refines image contrast and tonal response.
- **Configurable effects:** Unused shader effects can remain disabled to keep the preset simple.

## Requirements

- Grand Theft Auto V for PC.
- A compatible ReShade/SweetFX version.
- Compatibility with your GTA V edition and graphics API must be verified before installation.

## Installation

1. Back up your existing graphics injector files and configuration.
2. Install a compatible ReShade/SweetFX version, following its official instructions.
3. Place the permitted preset files in the appropriate GTA V directory.
4. Launch the game and verify that the effects load correctly.
5. Use **F12** to toggle the effects if supported by the installed configuration.

Do not overwrite existing injector files without backing them up.

## Configuration

The supplied configuration enables sharpening, levels, vibrance, and curves. Other effects can be enabled or disabled in `SweetFX/SweetFX_settings.txt`.

## Performance

The preset disables several optional effects, including bloom and film grain. Actual performance impact depends on hardware, game settings, resolution, and the installed shader framework.
